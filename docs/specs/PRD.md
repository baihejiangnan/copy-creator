### 3.3 翻译

| 项目 | 说明 |
|------|------|
| 交互方式 | 用户进入翻译 Tab → 在输入框粘贴/输入文本 → 点击翻译 → 显示翻译结果 |
| 引擎选择 | 设置中可选默认引擎：AI 翻译 / 内置免费翻译 |
| AI 翻译 | 用户配置兼容 OpenAI 格式的 API 端点（地址 + Key + 模型名），不限厂商 |
| 内置免费翻译 | 接入国内可直连的免费翻译服务（百度翻译 / 有道翻译），无需梯子 |

**翻译处理流程：**

```
用户粘贴文本 → 点击翻译
  ├─ 默认引擎为 AI 翻译 且 已配置 API Key → 调用大模型翻译 → 显示结果
  ├─ 默认引擎为内置翻译 或 未配置 API Key → 调用免费翻译 API → 显示结果
  └─ 请求失败 → 提示错误信息
```

### 3.5 网站资料与密码箱（2026-10-05）

以网站账号为单位保存文字资料，同一网站支持多个账号。基础字段包括网站名称、登录网址、账号、密码、注册邮箱和手机号，扩展字段包括标签、个人资料、自定义字段、验证方式及备注。支持编辑、删除和按网站 / 账号 / 联系方式搜索。

使用独立主密码解锁，加密保存所有业务字段；主密码长度自行决定，支持 6 位或其他任意非空长度，不接受全空白，主密码无法找回。生成器默认生成 24 位密码，可设置长度和字符类型。验证方式提供邮箱、短信、恢复码、安全问题及自定义模板；验证器模板只记录应用或设备说明，本期不生成 TOTP。

Windows 支持单项「填入」：先选中外部输入框，再通过快捷键呼出应用，选择字段后恢复目标焦点并粘贴。目标窗口 / 控件失效或焦点无法确认时取消。固定窗口可连续填入；不自动识别网页字段或提交表单。

自动锁定可选永不自动锁定、24小时、三小时（默认）或第一次打开应用时。定时选项按资料页空闲时间计算，隐藏或最小化窗口不会立即锁定；完全退出并重启应用后仍需主密码。锁定后清空前端资料和解密密钥，后端禁止读取、编辑、复制与填入。已经复制的内容保留 30 秒便于登录，清除时不覆盖用户随后复制的其他内容。

网站资料的搜索、按钮、菜单、表单和页面/卡片动效与剪贴板及随记保持同一视觉规范；自定义选择菜单适配小窗口、键盘和减少动态效果偏好，锁定不等待退场动画。当前浏览器验证已通过，真实桌面缩放与外部填入仍待联合验收。

完整规格、数据结构和验证方式见 [网站资料功能说明](../features/website-vault.md)。

设置页加密导出覆盖设置、收藏、API Key 和完整网站资料。导入支持跨设备恢复、不同主密码密码箱合并与旧 JSON 兼容，预览后确认，同 ID 保留本机资料，失败整体回滚。使用独立备份密码，恢复资料仍需对应主密码；详见 [加密备份与恢复](../features/encrypted-backup.md)。

## 4. 数据模型

下图保留早期核心模型。已有密码箱/备份见对应功能说明；便签页面、`notes`/`note_refs`、恢复来源表及备份/搬迁已接入，字段、派生搜索索引、版本及幂等规则以 [便签设计 §5](../features/notes-design.md) 为准。

```
clipboard_records
  ├─ id              UUID        PK
  ├─ type            TEXT        'text' | 'image'
  ├─ content         TEXT/BLOB   文本内容或图片二进制
  ├─ source_app      TEXT        来源应用名称
  ├─ created_at      DATETIME    索引
  └─ 清理: 按 created_at 删除过期记录

phrase_groups
  ├─ id              UUID        PK
  ├─ name            TEXT        场景组名称
  ├─ sort_order      INTEGER     排序
  ├─ created_at      DATETIME
  └─ updated_at      DATETIME

phrases
  ├─ id              UUID        PK
  ├─ group_id        UUID        FK → phrase_groups
  ├─ title           TEXT        短语标题
  ├─ content         TEXT        短语内容
  ├─ sort_order      INTEGER     排序
  ├─ created_at      DATETIME
  └─ updated_at      DATETIME

translation_history
  ├─ id              UUID        PK
  ├─ source_text     TEXT        待翻译文本
  ├─ target_text     TEXT        翻译结果
  ├─ source_lang     TEXT        源语言（自动检测 / 手动指定）
  ├─ target_lang     TEXT        目标语言
  ├─ engine          TEXT        'ai' | 'builtin'
  ├─ created_at      DATETIME    索引
  └─ 缓存: 相同 source_text + target_lang + engine 命中缓存直接返回

settings
  ├─ key             TEXT        PK
  └─ value           TEXT
```

## 6. 非功能需求

| 类别 | 要求 |
|------|------|
| 启动速度 | 冷启动 < 2 秒 |
| 内存占用 | 常驻 < 80MB |
| 包体积 | 尽力压缩；<20MB 为参考目标，用户明确接受未达到，不作为完成门槛 |
| 剪切板响应 | 复制后 < 100ms 完成记录 |
| 数据安全 | 所有数据仅存储于本地，无任何网络上传 |
| 跨平台一致性 | Windows 11 与 macOS 界面外观一致 |

速度和内存仍按整体产品目标验收；包体积根据 2026-10-08 用户“达不到也没事，尽力就行”的明确指示，20MB 改为参考目标，保留真实体积、改进与取舍证据。最新同 SHA NSIS/MSI 为 32.19/33.94 MB，不称已达到 20MB。前端目录、EXE/安装包和进程树内存分别计量；Windows 事件唤醒已在同环境完整默认 Release 的 60 次普通文本中将提交事件 P95 从 761ms 降至 36ms，最大 87ms；保留后台暂停/私密保护，图片/文件及持续系统压力另验，不能据此称全部场景达标。见[实测边界](../verification/2026-10-08-clipboard-events.md)。便签增量预算不替代整体目标，保留字体与美化是两个任务共同的交付要求。近上限备份、长正文、隐藏轮盘和并发保存须另报压力结果，方法见 [优化方案](../features/performance-design.md)。
