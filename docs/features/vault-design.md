# 保险箱：身份与资料功能及界面设计

2026-10-13。依据用户认可的[身份原型](../prototypes/vault/index.html)制定，供源码实现、评审和验收使用。本文是新版的主要设计位置；[原网站资料说明](website-vault.md)保留早期方案、现有保护合同与历史证据。任务状态统一维护在 [TODO](../TODO.md)，本文的设计要求不代表已通过桌面验收。

## 1. 产品结构

保险箱是独立主密码保护的私密资料空间。身份档案回答「用哪个身份」，资料条目记录「某项服务需要什么」。两者均为具名、有序、可自由编辑的文字字段集合，资料可关联零个、一个或多个身份。

| 对象 | 示例 | 规则 |
| --- | --- | --- |
| 身份档案 | 个人身份、工作身份、项目身份 | 保存邮箱、手机号、邮箱密码、公司等信息；名称可自定义、重名 |
| 资料条目 | GitHub · 工作、远端服务器相关、项目 API 凭据 | 保存对应服务自己的地址、账号、密码和说明 |
| 身份关联 | GitHub → 工作身份 | 按稳定 ID 关联，仅用于组织；不复制字段、不共用密码、不授予权限 |
| 独立资料 | 临时服务器、共享密钥 | 无关联时仍可完整使用，不强制先建立身份 |

身份邮箱修改不会改写任何网站账号；服务密码修改不会改变邮箱密码。本期不实现字段动态引用、整组自动填表、第三方认证、TOTP 生成、附件或云同步。翻译设置和受保护剪贴板 Key 不自动搬入保险箱，也不开放 Agent 读取接口。

## 2. 页面与导航

侧栏、主标题、解锁、设置与备份相关用户文案统一称「保险箱 / Vault」。源码模块名 `vault`、现有数据表和加密上下文沿用。

### 2.1 解锁与全局工具栏

首次使用设置独立主密码；已有保险箱输入主密码解锁。沿用非空且非全空白校验、无法找回的提示、失败退避及生成器。顶部保留锁定、自动锁定策略和修改主密码入口。编辑期间修改主密码入口禁用；锁定沿用现有清理合同。未保存修改离开时必须确认。

默认进入「身份档案」，旁边保留「全部资料」。两个入口共享页内导航，切换清空搜索、展开状态和显示密码状态，不操作外部输入目标。返回保留当前身份上下文；锁定、存储切换后清除身份上下文及明文草稿。

### 2.2 身份首页

标题「联系方式与服务，在这里关联」，短说明解释身份与关联资料。搜索覆盖身份名称、标签、字段名称及非敏感值。右侧「新建身份」，窄窗使用加号并保留完整可访问名称。

身份卡片纵向排列：左侧简洁字形标记，中间名称、非敏感摘要与关联资料数，右侧进入箭头和独立编辑按钮。卡片进入身份详情，不直接粘贴。邮箱优先作为预设摘要，用户可改为其他非敏感字段。下方提供「独立资料」入口及数量。空列表提供建立身份入口；搜索无结果提供清除搜索。

### 2.3 身份详情

顶部「所有身份」返回入口及编辑/删除按钮。显示身份名称、关联资料数；「身份信息」原生可折叠，默认展开，只显示有值字段。每个字段值可独立复制或粘贴；敏感值默认遮罩。

下方为「关联资料」，提供搜索、添加和资料列表。从这里新建时显式勾选当前身份，保存前可取消或另选身份。没有关联资料时提示新建或编辑已有资料来关联；不将整个保险箱无关资料混入当前列表。

### 2.4 全部资料与独立资料

显示所有服务资料，身份档案不计入服务条目数量。筛选支持全部、独立资料和指定身份。数据由原生筛选及分页，不向前端一次加载全部解密详情。分页每页 50；身份选择列表也按 50 分页，支持搜索，已选择的关联 ID 跨页保留。

资料卡片显示标题、一个非敏感摘要与身份关联。标题按钮只展开/收起；编辑、删除和关联身份跳转各自独立。最多展开一个资料条目，展开时按 ID 获取详情。其他条目的秘密值不预加载。删除按钮仅在展开详情中出现，减少误触。

## 3. 新建与预设

| 入口 | 首屏预设 | 初始字段 |
| --- | --- | --- |
| 新建身份 | 个人身份、工作身份、自定义身份 | 个人：邮箱、手机号、邮箱密码；工作：工作邮箱、手机号、邮箱密码、公司；自定义：空白 |
| 新建资料 | 自定义、网站账号、服务器 | 空白；网址/账号/密码；IP 或主机地址/认证密码 |
| 更多资料预设 | 数据库、API 凭据、恢复资料、个人资料、工作资料 | 沿用对应字段，并允许任意修改 |

预设只提供起点。选择时不写库，保存才创建。服务器默认恰好两个字段，不额外显示账号、邮箱或手机号空区。进入编辑后不提供会覆盖内容的模板切换；通过添加字段补充资料。已有个人/工作资料模板保留为普通资料，不自动转换成身份。

## 4. 通用编辑器

顶部身份名称或条目标题，必填、最多 120 字符。下方为关联身份选择（仅服务）、网站登录方式（仅网站预设）、有序字段、添加字段、折叠的标签与摘要选项、保存/取消。身份编辑器说明邮箱密码与服务密码各自用途。

字段具有稳定 ID、名称、类型、内容和独立敏感标记。名称最多 80 字符，允许重名；改名不改变 ID。上移/下移调整顺序，首尾对应按钮禁用；不依赖拖拽。删除有值字段前确认。输入、类型切换、生成器和排序均只修改草稿。

| 类型 | 呈现与行为 |
| --- | --- |
| 单行文字 | 账号、IP、邮箱、手机号等；保留前后空格，IP 不自动转成网址 |
| 密码 / 密钥 | 默认敏感，遮罩；支持现有完整密码生成器写入当前字段 |
| 网址 | 单行输入；保存支持 HTTP/HTTPS，省略协议补 HTTPS；拒绝内嵌凭据，独立打开按钮 |
| 多行文字 | 备注、恢复码与说明；保留换行及空格，不拆分或消费恢复码 |

敏感与类型分离。取消敏感前确认其值将可见且可搜索；改名或类型切换不能隐式取消。显示/隐藏只控制当前界面。密码、邮箱密码、API Key、恢复码和安全答案默认敏感。标签最多 20 个，每个最多 40 字符；字段值每项最多 16 KiB，整个业务载荷最多 256 KiB。新建界面最多 128 字段；完整旧资料转换可能超过 128，原生和兼容编辑最多容纳 256，不能截断旧资料。

自定义可以保存具名空条目。摘要只能选非敏感字段；选中字段删除或改敏感后自动回退为第一个有值非敏感字段。标题、标签和名称不应填写秘密。空字段在详情不占行，编辑时保留以便补充。

### 4.1 关联与登录方式

关联身份可多选或全部取消。默认勾选必须可见，不能只在保存时偷偷归类。删除身份前说明：仅删除身份及其关系，保留服务字段和其他身份关联；没有剩余身份的资料变为独立资料。变更必须在原生事务中完成。

网站登录方式为账号与密码、邮箱验证码、手机验证码、第三方账号、其他；可填最多 200 字符说明。它是登录信息记录，不生成验证码或完成认证，也不自动删除或增加字段。

### 4.2 保存与离开

显式保存，保存期间禁用重复提交和编辑；失败保留草稿与可读错误。取消/返回/导航遇到未保存修改时确认放弃，可继续编辑。编辑冲突不得静默覆盖新版本，提示重新加载；存储切换、锁定或过期响应不得把旧内容写到新存储或重新显示。沿用原生会话、operation 锁和存储身份，不落地明文草稿。

## 5. 单字段操作

标题只展开；字段值点击只执行一次粘贴，隐藏的密码也可点。独立复制、显示、网址、编辑和删除均不附带粘贴。拖选字段文字不发送内容；目标输入选中文字时，粘贴应替换该选区。

真实应用由 ID 驱动 `paste_vault_field`：原生读取字段、校验解锁/存储代次/目标，再使用私密剪贴板和目标恢复流程。复用现有普通剪贴板的操作模式与可复用执行部分，不能调用普通明文粘贴接口替代私密写入。保留历史排除、30 秒归属清理、权限检查及可见错误；无目标、目标失效或竞争时拒绝，不猜测字段、不自动重发或提交。跨平台未实现的保护不能降级。

原型右侧的示例输入区域仅用于设计演示，不进入正式应用页面。正式应用没有合成身份、服务器或密码种子，也不显示原型重置按钮。

## 6. 视觉规范

沿用应用 PingFang 400/500/600 与 `base.css` 的字体、CSS Variables、蓝色强调和自定义图标。原型桌面外框、右侧演示面板与预览工具栏是展示容器，正式页面嵌入现有主窗口。

| 元素 | 设计规格 |
| --- | --- |
| 页面背景 | `--panel-bg` / 现有页面底色；卡片使用 `--card-inner-bg`，浅暗模式均来自 token |
| 文字 | 主文字 `--text-primary`，说明 `--text-secondary`；标题 17～20px/600，卡片 13～14px/600，说明 10.5～12px |
| 强调 | 单一蓝色 `--accent`、`--accent-text`、`--accent-bg`；错误/危险操作使用现有红色 token |
| 分隔 | 1px `--separator`；避免新增大面积渐变或装饰阴影 |
| 圆角 | 卡片 12～14px，身份标记 9～12px，输入 9～10px，内部按钮 6～8px |
| 间距 | 页面沿用 18～22px 内边距；卡片间 8～10px；字段行上下 8～12px；大区块间 20～24px |
| 导航 | 两个文本入口、底部 2px 活跃指示线、低对比计数；非活跃使用次要文字 |
| 身份标记 | 简洁单字/首字母块，个人中性底色、工作淡蓝；不使用网络头像或站点 favicon 请求 |
| 数值与秘密 | 密码、密钥和 IP 使用现有等宽字体，计数启用 tabular-nums；长值折行，普通标题省略 |
| 交互 | hover 使用淡底色，pressed 轻微缩放；focus-visible 2px 蓝色可见轮廓，禁用状态保留辨识度 |
| 动效 | 约 180～220ms 的透明度/位移，减少动态效果时关闭；锁定清理不等待动画 |

440×420 等最小窗通过内容区滚动完成编辑与保存；不把手机网页宽度等同 Windows 系统缩放。窄窗隐藏新建文字保留加号与 aria-label，身份关联折行，字段操作避免挤压值。列表和编辑器单一主滚动，确认框不超出窗口；生成器和身份选择的长列表使用有界内部滚动。

中英文同步；长英文按钮、空状态和错误需实测。输入有可访问名称，展开使用 `aria-expanded`，身份区域使用原生 details/summary，确认框聚焦取消并支持键盘。状态提示使用 role=status，错误使用 role=alert。颜色不是唯一状态线索。

## 7. 数据与兼容合同

新版业务载荷 v2 包含 `kind`（identity/entry）、`template`、有序字段的类型、`identity_ids`、`summary_field_id`、`login_method`、`login_note` 与既有 ID/时间。字段的 `purpose` 保留旧验证种类及说明属性，空验证项仍保留为可编辑字段。旧固定属性只用于读取适配；写入新版时不同时保留隐藏旧值。旧记录默认是独立资料，不猜测身份。适配必须保留所有固定项、自定义字段、验证值与说明、空格、时间和 ID；派生字段 ID 必须稳定。

继续使用 `vault_entries` 加密整条业务 JSON，关系不建立明文索引。AES-GCM 的记录 ID AAD、封装前缀和校验串不变。首次 v2 写入与 `vault_config.version=2` 同事务；新版允许旧/新混合读取，旧应用拒绝 v2 配置。未知业务/配置版本拒绝。

身份关联在原生检查目标存在且类别正确；身份删除逐条重加密去除该关系，并与删除提交同一事务。新建草稿先生成稳定 UUID，丢失确认后的相同内容重放只返回已有 ID，不重复创建；保存校验旧 `updated_at`，不能覆盖已改变的记录。列表只返回非敏感摘要和有界分页，详情按需加载。

备份 `VaultBackup` 内层升级到 2，外层 v4 只有在旧解析器对内层 2 先验整包拒绝时保留。读取旧内层 1，导入保留稳定 ID；存在含糊 ID 冲突时拒绝，不能把新服务误接到无关身份。不同主密码合并需完整重加密，轮换保留业务版本与关系，搬迁保留配置版本和密文。导入沿用全部对象原子事务，不能半升级或覆盖目标存储。

## 8. 验收场景

| 类别 | 必须确认 |
| --- | --- |
| 身份 | 个人/工作/自定义可新建编辑；敏感邮箱密码遮罩；搜索和摘要排除秘密 |
| 关系 | 0/1/多个身份；身份改名后关联显示新名；删除只解绑，其他身份和服务字段保持 |
| 最小服务器 | 自定义标题、两个字段，无其他空区；IP/IPv6 和秘密原文保持 |
| 编辑 | 改名、排序、增删、类型/敏感确认、摘要回退、保存失败和冲突保留草稿 |
| 兼容 | 完整旧字段/验证说明无损适配；混合 v1/v2、未知版本拒绝和失败事务回滚 |
| 备份 | 旧读取、新往返、不同主密码合并、ID 冲突拒绝、轮换/搬迁关系保持、旧发行拒绝 |
| 操作区域 | 标题/字段分离；复制/显示/编辑/删除无额外粘贴；编辑不外发 |
| 桌面粘贴 | 隔离夹具至少 20 次 IP/密码交替实际插入，含浏览器/编辑器/终端和反向拒绝 |
| 视觉 | 中英/亮暗、最小窗、100%～200% 系统缩放、键盘、减少动态效果 |

原型初版与身份续轮的历史验证范围分别见 [10-12 记录](../verification/2026-10-12-vault-prototype.md)和 [10-13 记录](../verification/2026-10-13-vault-identity-prototype.md)。源码、静态检查、构建、隔离桌面和发行分别报告，不能互相替代。
