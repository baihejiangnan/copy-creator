## 范围与操作

待输入的备份密码、确认密码及两边主密码只属于当前存储会话；切换存储或当前身份的密码箱锁定时清空，旧目录迟到的锁定事件不得清空新目录刚输入的密码。页面 visibility 清理仍保留。该边界经真实默认 Release 的迁移/事件回放通过，见[表单回归](../verification/2026-10-08-vault-phrase-regression.md#备份密码输入的旧事件补查)。

设置页「数据导入导出」默认生成 v3 `.ccbackup` 加密文件，包含可导出的设置、翻译 API Key、收藏及收藏图片、API Key 记录/标签、完整网站资料/主密码配置，以及活动/归档便签、引用和来源快照。已识别、手动标记或带标签的 API Key 即使未收藏也会导出，收藏状态、服务、Base URL、备注和过期标记保留。便签不包含外部文件正文或最近删除项。

普通剪贴板历史、快捷短语、翻译历史和存储目录不在备份范围内。网站资料不支持图片；收藏图片沿用现有备份能力。

schema 5 的便签搜索索引与稳定映射属于派生数据，不增加 v3 文件内容或改变 v0/v1/v2 读取。导入普通便签/引用时目标库触发器在联合事务内维护索引，失败一并回滚；索引不包含密码箱或受保护 Key。默认接入获用户明确批准后已完成大规模搜索/保存和富内容回滚复验，其他共享验收继续；见[默认索引证据](../verification/2026-10-07-images-scale.md#完整默认配置索引复验)及[富内容证据](../verification/2026-10-08-rich-backup.md)。

导出时设置并确认备份密码（至少 12 个字符、最多 1024 字节，不能全为空格），再选择保存位置。备份密码和密码箱主密码分别使用，均无法找回。网站资料以现有密文备份，可以在锁定时导出。

导入时选择 `.ccbackup` 或旧 `.json` 文件。加密文件输入备份密码，点击「查看备份内容」，预览数量和恢复方式后确认。对应设置和翻译 API Key 会更新；记录按 ID 合并。

## 密码箱恢复与合并

| 本机状态 | 恢复方式 |
| --- | --- |
| 尚未建立密码箱 | 恢复备份主密码配置和资料密文，之后使用原主密码解锁 |
| 与备份主密码配置完全相同 | 直接合并密文，不额外要求主密码 |
| 主密码配置不同 | 输入备份原主密码与本机主密码，后端验证后用本机主密码重新加密导入资料 |
| 备份不含密码箱 | 保留本机密码箱 |

修改过主密码也属于配置不同的情况。即使主密码文字相同，两次独立建箱的随机盐不同，合并时也需要填写两边的主密码。备份密码不能替代密码箱主密码。

同 ID 网站资料保留本机内容，重复导入不产生副本。同 ID 收藏和 API Key 记录保留本机内容与已有备注，已有服务标签不被覆盖。网站资料导入完成后锁定密码箱。

## 跨设备与一致性

备份交接同样等待已接受的普通文字/图片/文件复制粘贴实际工作完成；排他操作期间六入口拒绝，不在选择文件或导入期间继续操作旧存储。最新默认 Release 的实际导出框 29 请求拒绝、取消恢复及认证恢复原文通过，见[共享复制交接](../verification/2026-10-08-copy-handoff.md)。

API Key 在原 Windows 用户环境中由后端解密，再与其他内容一起加密到备份。导入时重新用目标设备当前用户的 DPAPI 加密，因此新备份支持跨设备恢复；直接复制数据库仍受原 DPAPI 环境限制。

文件不保存明文 Key、DPAPI 原密文、网站名称或账号详情。全部内容加密成功后才写入同目录临时文件，再替换目标文件；加密失败不会覆盖已有备份。

设置、API Key、标签、密码箱、便签/引用及恢复来源在同一个 SQLite 事务中写入。密码错误、无效数据或写入失败不部分导入，预先写入的收藏图片也会清理。图片解码/校验/准备文件及尺寸测量在 DB 锁外；提交前复核 epoch，图片 ID 存在性在 `BEGIN IMMEDIATE` 的写保留内复核，尺寸台账与引用同事务提交，避免检查与提交间另一连接改变冲突结果。自动过期和容量清理继续保留受保护 Key；普通便签独立于剪贴板淘汰。相关回滚与冲突测试见[容量/原生记录](../verification/2026-10-07-accounting-desktop.md)。

## 兼容与限制

- 接受旧 JSON v0 / v1，无需备份密码。导入的 API Key 记录会在本机加密，当前翻译 API Key 与密码箱不被替换。旧文件自身仍可能含明文凭据，请妥善保管。
- 导入预览有效期 5 分钟，取消或切换文件时丢弃后端暂存内容，过期需重新选择。
- 加密文件最多 100 MiB，内部载荷最多 74 MiB，以预留 Base64 封装空间。过大文件在写入前拒绝。
- 默认格式 v3，继续读取加密 v2；v2/v3 使用独立认证数据。Argon2id v1.3 使用 64 MiB 内存、3 次迭代、并行度 1，派生 256 位密钥；AES-256-GCM 使用随机 96 位 nonce。每次导出生成新的 128 位随机盐，拒绝未知版本和任意 KDF 参数。旧应用拒绝 v3，不会悄悄忽略便签。
- 不增加云同步或明文导出选项。
