## 2026-10-12 保险箱升级方案（设计，尚未实施）

本轮将「网站资料」升级为通用的「保险箱」（英文 Vault）：在一个受主密码保护的空间中，用自定义标题组织网站账号、服务器认证、数据库连接、API 凭据、恢复资料及其他私密文字。网站账号成为其中一种预设。以下为新的产品与实施方案；后文保留现有实现合同和历史验证，不能将其视为新版已经落地的证据。任务状态统一见 [TODO](../TODO.md)。

续轮已交付[可交互原型](../prototypes/vault/index.html)及[启动说明](../prototypes/vault/README.md)：可体验预设、自由字段、标题展开、模拟输入框点击粘贴、锁定与主题/语言切换。最终脚本 20 次字段交替粘贴、选中文字替换及 16 组布局检查通过；原型仅用内存合成资料，不操作系统剪贴板或真实保险箱，不表示应用数据层和原生粘贴已经改版。实际范围与剩余边界见[原型验证](../verification/2026-10-12-vault-prototype.md)。

2026-10-13 用户提出以个人/工作身份组织网站、工作资料与服务器，并要求先做原型。当前页面已增补「身份档案 + 关联资料」，设计见下方 §10，实际检查见[身份原型记录](../verification/2026-10-13-vault-identity-prototype.md)。上段浏览器与 20 次输入证据属于 10-12 版本；本次仅脚本与模型检查通过，浏览器访问被自动安全检查拒绝，新界面的浏览器交互、尺寸和视觉检查尚未执行。

### 1. 定位与保留功能

用户面对的侧栏、页标题、解锁页、搜索提示、建箱/修改主密码、备份预览与错误提示统一使用「保险箱」，记录统一称「条目」。源码中的 `vault`、现有表名和文件路径继续使用，避免仅为更名改动加密协议或数据身份。介绍页和 README 在功能实际交付后同步，当前发行能力仍按现有说明展示。

| 方向 | 新方案 |
| --- | --- |
| 组织单位 | 每个条目有独立标题，例如「远端服务器相关」「GitHub · 工作」；同一服务允许多个条目 |
| 内容模型 | 标题 + 有序字段；网址、账号、密码、联系方式、备注均可按需添加和删除 |
| 预设作用 | 只提供初始字段和敏感默认值，用户选择后可完全修改，不强制保留固定字段 |
| 核心操作 | 找到条目 → 展开字段 → 点击所需字段值 → 粘贴到此前选中的外部输入框 |
| 沿用能力 | 主密码、自动锁定、密码生成、标签与搜索、个人/工作资料、各类验证方式、独立复制、编辑/删除、加密备份、主密码轮换和目录迁移 |

本期仍以文字为范围。TOTP 生成、附件、云同步、浏览器表单识别和整组自动填表保持原有范围。已有翻译 API Key 和剪贴板 Key 保护各自沿用，升级不自动搬入保险箱，不增加 Agent 读取保险箱接口。

### 2. 新建与预设

点击「新建条目」进入紧凑选择面板，首屏只有「自定义」「网站账号」「服务器」三个常用入口和「更多预设」。更多预设在同一面板中展开，可按名称搜索并内部滚动，不将全部字段直接铺在页面上。选择预设后进入同一个编辑器；没有必须完成的多步向导。

| 预设 | 初始字段 | 可通过「添加字段」补充的示例 |
| --- | --- | --- |
| 自定义 | 无预置业务字段 | 任意名称和文字内容 |
| 网站账号 | 网址、账号、密码 | 注册邮箱、手机号、个人/工作资料、验证方式、备注 |
| 服务器 | IP / 主机地址、认证密码 | 用户名、端口、连接方式、备注 |
| 数据库 | 主机地址、数据库名、账号、密码 | 端口、连接字符串、备注 |
| API 凭据 | 服务地址、API Key | 账号、项目标识、备注 |
| 恢复资料 | 恢复码（敏感多行） | 安全问题、验证器/通行密钥说明、备注 |
| 个人 / 工作资料 | 沿用现有两组资料模板 | 其他自定义字段 |

「服务器」默认只带两个字段，满足用户当前案例。账号、邮箱、手机号、验证方式等不出现空白占位或「尚无账号」提示。更多预设可以扩充，但不新增业务页面或改变编辑器。初版不加入自定义模板管理系统。

选择预设不创建记录、不写入数据；只有保存才创建。进入编辑后不提供会覆盖已填内容的「切换模板」操作，追加预设字段经「添加字段」完成。相同名称的字段允许并存，以稳定 ID 区分；重复追加前展示字段名称，由用户选择，不按本地化标签自动合并或覆盖值。

### 3. 编辑与字段规则

编辑器顶部为「条目标题」，下方依次显示实际存在的字段，底部提供「添加字段」「保存 / 取消」。标签作为折叠的可选信息，创建/更新时间放在详情底部。标题必填并沿用 120 字符上限，不以密码或其他字段值自动生成标题；标题允许重名。自定义新建先显示标题和添加字段入口，无字段也可保存为具名空条目。

每个字段具有名称、类型、内容和敏感属性。可改名、移动、删除，顺序直接决定详情顺序；通过上移/下移按钮与键盘操作完成，拖拽不是必需条件。有内容字段删除前确认，取消编辑或离开存在修改的编辑页沿用放弃确认。保存失败保留本次内存草稿与错误提示；锁定清空草稿的原有合同继续执行，不新增明文草稿持久化。

| 类型 | 行为 |
| --- | --- |
| 单行文字 | 默认类型，可用于账号、IP、主机名、端口、邮箱、手机号等；保留用户值 |
| 密码 / 密钥 | 默认敏感、遮罩显示，支持现有密码生成器写入当前字段；密钥不参与 URL 处理 |
| 网址 | 提供独立「打开网址」按钮；沿用 HTTP/HTTPS 校验和省略协议补 HTTPS，拒绝含内嵌凭据的网址 |
| 多行文字 | 用于备注、恢复码和说明；复制/粘贴完整原文，保留换行，不自动拆分或消费恢复码 |

敏感属性与展示类型分开：任何类型都可标记敏感；密码、API Key、恢复码、验证答案和自定义验证内容默认敏感。取消敏感需明确提示会显示值并允许搜索该值，不能由切换类型、追加预设或重命名隐式取消。显示/隐藏只改变可见性，不改变敏感属性。标题、标签和字段名称应填写识别信息，凭据放在字段值中。

IP / 主机地址不复用网址类型：`203.0.113.24`、IPv6 和主机名按文字保存，不能自动加 `https://`。账号/密码等复制粘贴取保存的原文，不做额外 trim 或格式化。字段名称必填、最多 80 字符；单值最多 16 KiB、验证说明最多 4 KiB、标签最多 20 个且每个最多 40 字符；单条序列化明文保持 256 KiB 上限。统一字段数量上限建议为 128，以容纳旧版 64 个自定义字段、32 个验证方式及基础字段的无损映射；这些上限由原生强制执行。

### 4. 列表、详情与点击区域

列表沿用当前单栏、搜索框、主题、字体和菜单。条目卡片以标题为第一层，次行可展示一个由用户选定的非敏感字段摘要及少量标签；未选择摘要时使用第一个非敏感且有值的字段，没有则只显示标题。敏感字段不能作为摘要，修改为敏感时立即移除旧摘要。预设名称仅作小型提示，不能替代条目标题。卡片高度随实际内容收缩，不再固定显示网址与账号，也不输出「无网站」等无关信息。

点击卡片标题/主体在模块内展开该条目的字段；再次点击标题可收起，同时最多展开一个。列表仅请求摘要，展开时读取该条目完整内容，保留现有请求失效与存储身份保护。条目右上角提供编辑及更多操作，删除仍确认。详情使用同一个字段列表，不再固定出现「基础账号」「个人资料」空分区。亮/暗主题、中/英、最小窗口与减少动态效果要求沿用现有规范。

```text
保险箱                         锁定  ⋯
[ 搜索标题、标签或非敏感字段 ]    [ + ]

远端服务器相关                    编辑  ⋯
  IP / 主机地址   203.0.113.24     复制
  认证密码        ••••••••••••    显示  复制
  点击字段值，粘贴到此前选中的输入框
```

点击字段值区域执行单次粘贴，包括遮罩中的密码。标题、字段名称、卡片空白、标签均不触发粘贴；显示、复制、网址打开、编辑和菜单各有独立按钮，必须阻止冒泡造成额外粘贴。网址值点击粘贴，打开网址使用单独图标。字段值区域使用可聚焦按钮语义，Enter/Space 等同点击；Tab、显示切换、选中文字和右键菜单本身不触发粘贴。编辑模式的输入框只编辑，不能点击即向外粘贴。空字段在详情隐藏，空条目提供编辑入口；编辑器仍保留空字段。

### 5. 单字段点击粘贴

面向用户统一称「粘贴」，替换含糊的「自动填入」。操作与剪贴板卡片一致，但一次明确选择一个字段：

1. 在目标应用中点中输入框，通过现有快捷键呼出 Copy Creator。
2. 打开保险箱、按需要解锁，展开「远端服务器相关」。
3. 点击 IP 字段值，将 IP 粘贴到刚才的输入框。
4. 点中目标应用的密码输入框，再呼出应用并点击密码字段值。固定窗口时可直接在两边切换。

点击条目整体不拼接所有值，也不猜测应填 IP 还是密码。每次只发一个粘贴动作，不发 Tab、不提交表单；多行值仍按用户明确选择整体粘贴。保留独立「复制」供手动粘贴。解锁、搜索、展开和编辑不能将本应用的输入框记录为外部目标；固定窗口在用户重新选中外部控件后更新目标。

源码核对发现，当前 `paste_vault_field` 已通过 `paste_sensitive_text` 使用私密剪贴板与 Ctrl+V，并没有浏览器表单识别。普通粘贴对部分无控件句柄目标允许回退，私密粘贴要求确认保存的窗口和控件；当前私密路径也没有完全共用普通路径的有界等待。**这些差异是后续排查方向，不能认定为用户所述失败的已确认根因。** 普通粘贴同样有连续点击偶发空输入的历史证据，复用路径不代表可靠性自然达标。

实施时抽取共用的目标捕获、焦点恢复、有界等待与按键释放执行部分。保险箱继续通过记录 ID + 字段 ID 由原生读取保存值，经独立受保护写入策略执行，不能转发给普通 `paste_text` 或先生成剪贴板历史记录。私密操作必须校验解锁、存储身份、生命周期许可、目标进程/线程和控件归属、权限、剪贴板序列与修饰键；不能靠放宽到任意前台窗口来消除失败。没有可确认的目标时，在写入凭据和发送按键前提示用户重新选择输入框，用户可显式选择复制。

对没有独立原生输入控件的浏览器/终端，先以合成页面/终端复现并区分宿主窗口、焦点跟踪与时序问题；若需要宿主焦点策略，须单独定义并验证同一目标身份与误投拒绝，不直接照搬普通路径的宽松回退。共用等待必须有上限，超时显示可重试错误，不循环或自动重发。

应用级粘贴互斥继续覆盖普通与私密路径，前端禁用当前操作期间的重复点击，不排队累积凭据。目标失效或剪贴板被替换时取消，按归属清理本次私密内容并恢复可见错误；用户随后复制的内容不能被清掉。IPC 成功只能提示「已发送粘贴」，真实插入结果由桌面验收确认，不能显示「填写成功」并推断目标已接收。

30 秒私密剪贴板保留、应用历史跳过、Windows 历史与云剪贴板排除、锁定/退出及迁移清理保持原有合同。所有保险箱字段都走私密路径，字段的非敏感属性只控制展示和搜索，不表示可以写入普通历史。macOS/Linux 的私密复制/粘贴缺口继续按[跨平台准备](cross-platform-release.md)补齐，尚未支持时给出原生明确错误，不能悄悄降级明文普通复制。

### 6. 数据模型与旧资料兼容

建议在现有加密行内部引入显式业务载荷 `format_version: 2`，统一为有序字段集合；不在数据库新增明文标题、字段或搜索索引。以下是设计形状，不代表当前 Rust/TypeScript 类型：

```text
VaultEntryV2
  format_version: 2
  id, title, tags, created_at, updated_at
  template_id?: 内置预设标识，仅作来源提示
  summary_field_id?: 指向本条目一个非敏感字段
  fields[]:
    id, label, type, value, sensitive
    semantic?: username / password / email / phone / website / notes 等
    verification?: { kind, note }  // 兼容现有各验证方式与说明
```

数组顺序就是显示顺序。字段 ID 在重命名、移动和类型变化时保持；复制/粘贴只接受当前条目所属 ID，不按标签或数组下标查值。`semantic` 和预设不能强制字段存在；验证类型、敏感默认值和说明完整保留，不把恢复码或答案降级为普通备注。所有内容与组织元数据仍在原密文中，继续使用现有主密码及 Argon2id / AES-GCM 方案；本次展示更名不修改现有 AAD、主密码校验串或密文封装 `v1:`。

| 旧字段 | 新模型映射 |
| --- | --- |
| `title`、标签、UUID、时间 | 保留原值和原身份 |
| `website/username/password/email/phone/notes` | 非空项映射为有固定语义的字段；密码默认敏感；网址与备注类型分别保留 |
| `fields[]` | 原名称、值、敏感属性和 ID 保留 |
| `verification[]` | 原 ID、类型、名称、值、说明及现有敏感规则保留 |

未带业务版本的旧载荷只在解锁后映射到内存展示，不因浏览或改名立即重写所有密文。基础字段适配 ID 使用与自定义/验证字段区分的保留命名空间，读适配后可稳定解析；写入时校验重复、外来或未知 ID。旧自定义空值字段仍保留在编辑器内，详情隐藏；旧记录的字段标签按当时值保留，切换语言不重写用户名称。迁移不对旧值再次 trim、URL 规范化或覆盖时间。

首次写入新版条目时，在一个事务中将 `vault_config.version` 升至 2 并提交新版密文；新实现明确支持配置版本 1/2、以及配置版本 2 下混合的旧/新载荷。旧应用目前只接受配置版本 1，必须拒绝打开新版保险箱，避免 serde 忽略新字段后重写丢失数据。未知配置/载荷版本明确拒绝，不按旧版猜测。事务失败则配置版本和条目均保持原样；仅做界面更名不触发版本升级。

### 7. 备份、轮换与迁移合同

这是业务载荷升级，不要求仅为名称提升全局 SQLite schema。现有表和加密封装可以沿用，但 `config`、读取/保存、主密码轮换、`VaultBackup` 校验、备份合并与密文搬迁都必须一起支持新版配置及混合载荷；当前复制辅助函数中的配置版本固定值不能继续写回 1。

加密备份外层暂沿用当前 v4，保险箱内层 `VaultBackup.version` 随配置使用 1/2；旧 v4 及更早受支持备份继续可读。源码中的旧 `validate_backup` 已明确拒绝内层非 1 版本，实施时须以旧发行解析器反向验证新版保险箱备份会在任何写入前整包拒绝，不能只跳过保险箱而导入其他对象。若无法保留这一拒绝条件，必须改用新的外层认证版本，不能兼容性猜测导入。

同配置密文合并不能只比较盐和 verifier，须同时检查业务格式能力；旧备份向已升级保险箱导入时保持目标版本 2。旧目标接收新版来源时，版本提升与全部导入同事务。不同主密码合并按来源版本读取和验证，用本机密钥重新加密，完整保留字段顺序、敏感属性和验证说明。同 ID 本机优先、重复不增条、恢复后锁定、失败联合回滚和 74/100 MiB 预算沿用现有合同。

目录切换仍在统一保存/排空屏障内锁定会话，保留实际配置版本与全部密文，不覆盖目标原有保险箱。锁定状态的备份与同配置搬迁不能要求解密所有行。标题和字段结构不进入普通随记、明文日志或磁盘索引；目录切换后，旧搜索、展开、保存、粘贴结果和锁定事件继续按存储身份及会话代次失效。

### 8. 搜索、保存与实施边界

解锁后搜索标题、标签、字段名称及非敏感字段值，空格分词保持「全部匹配」。敏感值不参与搜索；锁定时不保留标题/摘要/查询缓存。列表摘要不得包含敏感值，即使密码已在详情临时显示也一样。继续先返回摘要、按需读取详情；列表改为每批至多 50 条并提供继续加载，不能将全部字段为点击粘贴常驻前端。单次请求合并与迟到响应拒绝继续保留；后端目前全库逐条解密的热点需单独测量，不因限制返回条数就宣称扫描量已受限。

编辑仍显式保存，保留保存失败和放弃确认。手动锁定、空闲到期、退出/重启与目录切换继续遵守既有会话保护，最小化/隐藏不增加强制锁定。密码箱草稿的现有锁定清空规则与普通随记草稿恢复不同，升级不自行引入普通便签保存协调器存储私密值。

实施顺序为：先做合成数据界面原型与字段点击区域；再落地原生版本兼容和统一字段模型，同时接入备份/轮换/搬迁；之后将列表、编辑器与中英文文案接到新版模型；最后复用粘贴执行部分并完成隔离桌面验收。已有 S 项保存/存储身份合同复用，不重开一套基础任务。原型可用假数据独立推进，真实数据写入必须等待版本门闸及备份回归到位。任务拆分与状态只维护在 [TODO](../TODO.md)。

### 10. 身份档案与关联资料（2026-10-13 原型续轮）

保险箱同时容纳「身份档案」与「资料条目」。身份保存常用邮箱、手机号、邮箱密码、公司等信息；网站账号、服务器、数据库、API 凭据等仍是独立资料。身份是可选的组织中心，不是每条资料的必填前置，也不代表共用密码或授予访问权限。

| 入口 | 原型行为 |
| --- | --- |
| 身份档案 | 默认首页，显示个人/工作等身份、非敏感摘要、关联资料数；可搜索身份、邮箱、手机号及新增/编辑身份 |
| 身份详情 | 身份信息可展开/收起，邮箱密码保持遮罩；下方列出关联资料，并可直接添加已勾选当前身份的新资料 |
| 全部资料 | 跨身份查找服务资料，可按某一身份或独立资料筛选；身份档案本身不混入服务列表计数 |
| 独立资料 | 没有关联身份的资料仍能保存、编辑、搜索与单字段粘贴 |
| 编辑关联 | 可选择零个、一个或多个身份；在身份详情中新建会显式勾选当前身份，保存前可以取消 |

身份同样使用具名自由字段编辑器。个人身份初始提供邮箱、手机号、邮箱密码；工作身份增加公司；自定义身份为空白起点。邮箱密码默认敏感，网站/服务器密码保存在各自资料中。服务与身份之间只保存关联 ID，不复制身份字段、不隐式继承密码，也不因邮箱修改自动更改服务的账号。原型需要身份信息时进入对应身份查看或点击单字段填入，不实现字段引用/动态继承。

网站账号可以记录「账号与密码 / 邮箱验证码 / 手机验证码 / 第三方账号登录 / 其他方式」及可选登录说明。这是登录信息记录，不会自动删改字段、请求验证码、生成通行密钥或调用第三方认证。

删除身份前说明影响并确认：只移除身份及其关系，服务资料和服务凭据保留；若资料还有其他身份，继续保留关联；若没有，则显示在独立资料中。删除服务条目也不删除身份。本页全部是可重置的合成数据，无实际认证、加密与存储。

原生接入前需重新核对业务载荷及备份版本：身份类别、稳定关联 ID、登录方式与说明必须加密存储，搜索/摘要仍排除敏感值，不加入明文关系索引；旧记录默认保持独立资料，不自动猜测个人或工作归属。合并导入时须保留/映射关联 ID，身份删除和关系变更需原子完成，备份/主密码轮换/目录搬迁不得丢失或串联关系。§5～§6 的 v2 仍是实施计划，不能将原型对象直接作为已确定的持久化协议。

## 使用流程

1. 打开侧栏「网站资料」，设置并确认独立主密码，长度自行决定（例如 6 位），不能为空或全是空白。主密码无法找回，忘记后无法解密。
2. 新增账号，填写网站 / 账号名称和网站或登录网址。省略网址协议时按 HTTPS 处理。
3. 填写账号、密码、注册邮箱和手机号。四项都有独立字段；允许为空以适配单点登录等情况。
4. 可生成强密码，加入个人 / 工作资料模板，或添加任意文字字段。每个自定义字段都有名称、内容和敏感标记。
5. 添加网站实际使用的验证方式，保存后在列表搜索并打开详情查看、复制、填入或编辑。

同一网站可建立多条账号记录，例如「GitHub · 工作」和「GitHub · 个人」。编辑后返回详情；放弃未保存修改和删除账号均有界面确认。

## 界面与动效

网站资料沿用剪贴板/随记的 `SearchInput`、字体、主题 token 和菜单表面；搜索与新增按钮同排，列表卡片固定 116px，长名称/网址/账号/标签省略，详情保留完整内容。详情、编辑、主密码及解锁使用一致的圆角、输入边框与留白，填入为浅蓝按钮，删除操作使用浅红提示。

自动锁定、个人资料模板和验证方式模板与随记分组共用 `SelectMenu`：菜单宽至多 232px、高至多 240px，按视口向上/下展开并内部滚动；支持方向键、Home/End、Enter/Space、Escape、Tab 和焦点返回。鼠标点击没有黑色系统外圈，键盘聚焦仍有可见提示。排队的旧滚动事件不会误关新菜单，实际移动触发器的滚动、缩放/失焦或外部点击关闭菜单。

切页使用 220ms 淡入/轻位移，卡片 350ms 入场、错峰只计算前 6 个位置（后续延迟不再增长），箭头 240ms 旋转，按钮有悬停/按压反馈；遵守系统减少动态效果偏好。敏感内容不参与退场保留：锁定立即卸载列表、详情和编辑草稿。浏览器合成资料验证与真实桌面边界见[样式同步验证](../verification/2026-10-10-vault-style.md)。

## 密码与锁定

- 生成器界面支持 12–64 位，默认 24 位，可选大小写字母、数字、符号和排除相似字符。Rust 使用操作系统随机源；至少包含每种已选字符类型。
- 建箱、解锁和修改主密码不限制位数，支持 6 位及其他任意非空长度，不接受全空白。解锁连续错误 5 次后等待 30 秒才能再次尝试。
- 网站资料页可选择自动锁定时间：永不自动锁定、24小时、三小时（默认）、第一次打开应用时。24小时和三小时按资料页空闲时间计算；隐藏、最小化、切换窗口或填入资料不会立即锁定。设置保存到本地并随加密备份导出、恢复。
- 「永不自动锁定」和「第一次打开应用时」在本次运行期间保持解锁，仍可手动锁定；完全退出并重启应用后需重新输入主密码，解密密钥不写入磁盘。
- 手动锁定或到达所选空闲时间后，清空前端记录、详情和未保存草稿，释放解密密钥。后端再次校验权限，锁定时禁止搜索、读取、保存、删除、复制、填入或修改主密码。
- 密码、恢复码、安全问题答案、自定义验证内容和标记敏感的资料默认隐藏；可在解锁后显示或复制。
- 修改主密码验证旧密码，并在 SQLite 单个事务中重新加密全部资料。任意记录无法解密或数据库写入失败时回滚，保留原主密码与数据。

目录切换后，旧密码箱请求、锁定事件与活动/复制剪切回调不能作用于新目标。变更和私密读取绑定存储身份，原生在许可内检查；主密码提前拒绝时仍清理。锁定事件携带会话操作时的来源身份，前端只接受当前身份；临时后台忙不会被当成锁定。默认 Release 已复验旧请求拒绝、旧锁定/活动错误失效、当前锁定，以及不同主密码合并/旋转与完整数据保持，见[会话回归](../verification/2026-10-08-vault-phrase-regression.md#密码箱旧请求与会话事件补查)。未以这些场景代替全部视觉/系统填入验收。

## 快速填入

Windows 详情页的账号、密码、邮箱、手机号、自定义资料、验证内容及备注均支持单项「填入」：

1. 在浏览器或桌面应用中点击目标输入框，选中文字时会按普通粘贴行为替换。
2. 使用已配置的窗口呼出快捷键打开 Copy Creator，解锁资料库并找到记录。
3. 点击对应字段的「填入」。应用恢复此前窗口和控件焦点，确认成功后发送 Ctrl+V。密码保持隐藏也可填入。

未固定窗口时会隐藏，资料库继续遵循所选自动锁定时间。固定窗口可保持可见，便于选中下一个输入框后连续填入。每次只填入选定字段的完整内容（多行字段也保留原文），不会按 Tab 切换字段或自动提交表单，也不自动识别网页账号 / 密码输入框。

后端只接收记录 ID 和字段标识，解锁校验后读取保存值，使用受保护的剪贴板路径。一次操作固定目标窗口、控件及所属进程 / 线程；目标关闭、控件失效、焦点恢复未确认、修饰键仍按下或剪贴板被替换时取消填入。交接失败时尝试清除该次资料剪贴板内容，并重新显示应用及错误提示。目标程序必须允许普通粘贴；浏览器 / 系统限制仍可能阻止实际输入。

## 剪贴板行为

跨平台首轮开发中，非 Windows 私密复制在原生写入前返回明确的“不支持归属保护与到期清除”提示，不再退化为普通明文剪贴板写入；私密填入仍不支持。下述 30 秒、归属和历史排除行为是 Windows 当前合同，macOS/Linux 完整原生实现与桌面验收仍是发布前要求，见[跨平台准备](cross-platform-release.md)。

普通权限应用向管理员目标填入时，原生在复制资料前拒绝并显示权限提示。可选择先使用复制按钮、手动粘贴，或点击「以管理员权限重启」。重启遵守统一便签/设置保存与 UAC 确认，密码箱先锁定，敏感剪贴板按原规则清理；取消授权保留应用运行，但需重新解锁已锁定的密码箱。新进程不会接收或自动重放凭据，用户重新选择目标、解锁并填入。实际 UAC 授权/取消和私密目标桌面验收尚待补齐，见[终端权限记录](../verification/2026-10-09-terminal-permissions.md)。

资料页复制、填入按钮和键盘复制 / 剪切均经过专用命令。本应用剪贴板监听器跳过这些内容；原生写入同时设置 Windows 历史与云剪贴板排除标记。

复制后保留 30 秒，窗口自动隐藏后仍可粘贴到登录表单。到期只清除密码箱仍拥有的那次剪贴板内容；用户随后复制了其他内容时不会清除。锁定期间不能再次复制资料。

从托盘主动退出时也会锁定，并尝试提前清除仍由资料库拥有的剪贴板内容。

## 本地存储与边界

- 数据存放在应用当前 SQLite 数据库中；不新建明文 JSON、浏览器本地存储或明文搜索索引。更换存储目录时会锁定资料库，以事务复制主密码配置和全部密文，再切换数据库连接，原库仍保留。目标已有网站资料库时拒绝迁移，避免混用主密码。
- `vault_config` 保存格式版本、随机盐和加密校验值，不保存主密码或解密密钥。
- `vault_entries` 保存记录 UUID、密文和时间戳；名称、网址、账号、密码、联系方式、标签、扩展资料及备注全部在密文内。
- Argon2id v1.3 参数：64 MiB 内存、3 次迭代、并行度 1、256 位密钥。AES-256-GCM 每次写入使用新 96 位随机 nonce，附加认证数据绑定格式版本和记录 ID。
- 主密码加密独立于现有翻译 API Key 的 Windows DPAPI 保护。
- 设置页加密备份包含完整网站资料与主密码配置，也包含 API Key，支持跨设备恢复、密码箱合并及旧 JSON 导入；恢复后解锁仍需对应主密码。详见 [加密备份与恢复](./encrypted-backup.md)。
- 当前不提供云同步、图片附件、自动识别网页字段并批量填表的浏览器扩展或 TOTP 动态验证码。
