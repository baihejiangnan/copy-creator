# 网站资料与密码箱

2026-10-05：源码已实现。现有 v0.2.24 发布包尚未包含此功能。

## 使用流程

1. 打开侧栏「网站资料」，设置并确认独立主密码，长度自行决定（例如 6 位），不能为空或全是空白。主密码无法找回，忘记后无法解密。
2. 新增账号，填写网站 / 账号名称和网站或登录网址。省略网址协议时按 HTTPS 处理。
3. 填写账号、密码、注册邮箱和手机号。四项都有独立字段；允许为空以适配单点登录等情况。
4. 可生成强密码，加入个人 / 工作资料模板，或添加任意文字字段。每个自定义字段都有名称、内容和敏感标记。
5. 添加网站实际使用的验证方式，保存后在列表搜索并打开详情查看、复制、填入或编辑。

同一网站可建立多条账号记录，例如「GitHub · 工作」和「GitHub · 个人」。编辑后返回详情；放弃未保存修改和删除账号均有界面确认。

## 字段与模板

| 分类 | 字段 / 模板 |
| --- | --- |
| 网站 | 名称、网址、标签 |
| 基础账号 | 用户名、密码、注册邮箱、注册手机号 |
| 个人资料模板 | 姓名、昵称、生日、国家 / 地区、联系地址 |
| 工作资料模板 | 姓名、公司、职务、工作邮箱、员工编号 |
| 自定义资料 | 可命名、修改、删除的多行文字字段，可标记为敏感 |
| 二次验证 | 邮箱验证码、短信验证码、恢复码、安全问题、验证器应用、通行密钥 / 安全密钥、自定义方式 |
| 其他 | 补充备注、创建与更新时间 |

验证方式可以并存，也能重命名。邮箱 / 短信模板填写接收验证码的联系方式；恢复码每行一条；安全问题可在说明中填写问题，在内容中填写答案。验证器和通行密钥模板记录应用、设备或保存位置。本期不保存 TOTP 密钥并生成验证码，不存图片。

搜索覆盖名称、网址、账号、邮箱、手机号、标签、备注和未标为敏感的自定义字段。按空格输入多个关键词时，各关键词都要匹配。密码、恢复码、验证答案及敏感字段值不参与搜索。

## 界面与动效

网站资料沿用剪贴板/随记的 `SearchInput`、字体、主题 token 和菜单表面；搜索与新增按钮同排，列表卡片固定 116px，长名称/网址/账号/标签省略，详情保留完整内容。详情、编辑、主密码及解锁使用一致的圆角、输入边框与留白，填入为浅蓝按钮，删除操作使用浅红提示。

自动锁定、个人资料模板和验证方式模板与随记分组共用 `SelectMenu`：菜单宽至多 232px、高至多 240px，按视口向上/下展开并内部滚动；支持方向键、Home/End、Enter/Space、Escape、Tab 和焦点返回。鼠标点击没有黑色系统外圈，键盘聚焦仍有可见提示。排队的旧滚动事件不会误关新菜单，实际移动触发器的滚动、缩放/失焦或外部点击关闭菜单。

切页使用 220ms 淡入/轻位移，卡片 350ms 入场、错峰只计算前 6 个位置（后续延迟不再增长），箭头 240ms 旋转，按钮有悬停/按压反馈；遵守系统减少动态效果偏好。敏感内容不参与退场保留：锁定立即卸载列表、详情和编辑草稿。浏览器合成资料验证与真实桌面边界见[样式同步验证](../verification/2026-10-10-vault-style.md)。

## 密码与锁定

- 生成器界面支持 12–64 位，默认 24 位，可选大小写字母、数字、符号和排除相似字符。Rust 使用操作系统随机源；至少包含每种已选字符类型。
- 建箱、解锁和修改主密码不限制位数，支持 6 位及其他任意非空长度，不接受全空白。解锁连续错误 5 次后等待 30 秒才能再次尝试。
- 网站资料页可选择自动锁定时间：永不自动锁定、24小时、三小时（默认）、第一次打开应用时。24小时和三小时按资料页空闲时间计算；隐藏、最小化、切换窗口或填入资料不会立即锁定。设置保存到本地并随加密备份导出、恢复。
- 「永不自动锁定」和「第一次打开应用时」在本次运行期间保持解锁，仍可手动锁定；完全退出并重启应用后需重新输入主密码，解密密钥不写入磁盘。
- 手动锁定或到达所选空闲时间后，清空前端记录、详情和未保存草稿，释放解密密钥。后端再次校验权限，锁定时禁止搜索、读取、保存、删除、复制、填入或修改主密码。
- 密码、恢复码、安全问题答案、自定义验证内容和标记敏感的资料默认隐藏；可在解锁后显示或复制。
- 修改主密码验证旧密码，并在 SQLite 单个事务中重新加密全部资料。任意记录无法解密或数据库写入失败时回滚，保留原主密码与数据。

目录切换后，旧密码箱请求、锁定事件与活动/复制剪切回调不能作用于新目标。变更和私密读取绑定存储身份，原生在许可内检查；主密码提前拒绝时仍清理。锁定事件携带会话操作时的来源身份，前端只接受当前身份；临时后台忙不会被当成锁定。默认 Release 已复验旧请求拒绝、旧锁定/活动错误失效、当前锁定，以及不同主密码合并/旋转与完整数据保持，见[会话回归](../verification/2026-10-08-vault-phrase-regression.md#密码箱旧请求与会话事件补查)。未以这些场景代替全部视觉/系统填入验收。

## 快速填入

Windows 详情页的账号、密码、邮箱、手机号、自定义资料、验证内容及备注均支持单项「填入」：

1. 在浏览器或桌面应用中点击目标输入框，选中文字时会按普通粘贴行为替换。
2. 使用已配置的窗口呼出快捷键打开 Copy Creator，解锁资料库并找到记录。
3. 点击对应字段的「填入」。应用恢复此前窗口和控件焦点，确认成功后发送 Ctrl+V。密码保持隐藏也可填入。

未固定窗口时会隐藏，资料库继续遵循所选自动锁定时间。固定窗口可保持可见，便于选中下一个输入框后连续填入。每次只填入选定字段的完整内容（多行字段也保留原文），不会按 Tab 切换字段或自动提交表单，也不自动识别网页账号 / 密码输入框。

后端只接收记录 ID 和字段标识，解锁校验后读取保存值，使用受保护的剪贴板路径。一次操作固定目标窗口、控件及所属进程 / 线程；目标关闭、控件失效、焦点恢复未确认、修饰键仍按下或剪贴板被替换时取消填入。交接失败时尝试清除该次资料剪贴板内容，并重新显示应用及错误提示。目标程序必须允许普通粘贴；浏览器 / 系统限制仍可能阻止实际输入。

## 剪贴板行为

普通权限应用向管理员目标填入时，原生在复制资料前拒绝并显示权限提示。可选择先使用复制按钮、手动粘贴，或点击「以管理员权限重启」。重启遵守统一便签/设置保存与 UAC 确认，密码箱先锁定，敏感剪贴板按原规则清理；取消授权保留应用运行，但需重新解锁已锁定的密码箱。新进程不会接收或自动重放凭据，用户重新选择目标、解锁并填入。实际 UAC 授权/取消和私密目标桌面验收尚待补齐，见[终端权限记录](../verification/2026-10-09-terminal-permissions.md)。

资料页复制、填入按钮和键盘复制 / 剪切均经过专用命令。本应用剪贴板监听器跳过这些内容；原生写入同时设置 Windows 历史与云剪贴板排除标记。

复制后保留 30 秒，窗口自动隐藏后仍可粘贴到登录表单。到期只清除密码箱仍拥有的那次剪贴板内容；用户随后复制了其他内容时不会清除。锁定期间不能再次复制资料。

从托盘主动退出时也会锁定，并尝试提前清除仍由资料库拥有的剪贴板内容。

## 本地存储与边界

- 数据存放在应用当前 SQLite 数据库中；不新建明文 JSON、浏览器本地存储或明文搜索索引。更换存储目录时会锁定资料库，以事务复制主密码配置和全部密文，再切换数据库连接，原库仍保留。目标已有网站资料库时拒绝迁移，避免混用主密码。
- `vault_config` 保存格式版本、随机盐和加密校验值，不保存主密码或解密密钥。
- `vault_entries` 保存记录 UUID、密文和时间戳；名称、网址、账号、密码、联系方式、标签、扩展资料及备注全部在密文内。
- Argon2id v1.3 参数：64 MiB 内存、3 次迭代、并行度 1、256 位密钥。AES-256-GCM 每次写入使用新 96 位随机 nonce，附加认证数据绑定格式版本和记录 ID。
- 主密码加密独立于现有翻译 API Key 的 Windows DPAPI 保护。
- 设置页加密备份包含完整网站资料与主密码配置，也包含 API Key，支持跨设备恢复、密码箱合并及旧 JSON 导入；恢复后解锁仍需对应主密码。详见 [加密备份与恢复](./encrypted-backup.md)。
- 当前不提供云同步、图片附件、自动识别网页字段并批量填表的浏览器扩展或 TOTP 动态验证码。
