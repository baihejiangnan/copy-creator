# 链接胶囊：复制链接与路径时的快捷操作

2026-10-25。用户要求「复制链接或文件路径时在屏幕顶部弹出一个可点击的胶囊」。本页说明功能范围、识别规则、界面行为与设置项，供源码实现、评审和验收使用；实现进度与验收状态统一维护在 [TODO](../TODO.md)。

胶囊是剪贴板采集的旁路提示：它不改变普通记录、不新增业务表，也不进入备份。源码、设置项、中英文文案、窗口入口与原生命令均已接入，并在隔离桌面副本上完成真实剪贴板触发与窗口交互验证（见第 6 节）。

## 1. 功能概述

主窗口在后台监听剪贴板时，若新复制的文本是一个网址或一个存在的本地文件/文件夹路径，就在屏幕顶部显示一个独立无边框窗口（胶囊）。胶囊左侧显示类型图标，中间显示截断后的内容，右侧提供「打开」与「关闭」操作。停留时间到后自动淡出，鼠标悬停时暂停倒计时。

- 胶囊只对**本次复制动作**提示，不回溯历史记录。
- 提示内容不写入数据库，不复用剪贴板记录的 ID 或时间戳。
- 关闭胶囊不影响主窗口，也不影响剪贴板历史本身。

## 2. 识别规则

原生侧在写入普通记录后做一次判定，命中才显示胶囊。判定顺序与边界：

| 条件 | 规则 |
| --- | --- |
| 开关 | `capsule_enabled` 不为 `1` 时一律不提示 |
| 文本清洗 | 先 `trim`，再按需去掉首尾成对的双引号；空串、超过 2048 字符、含控制字符时不提示 |
| 网址 | 需 `capsule_url_enabled` 为 `1`；前缀为 `http://`、`https://` 或 `www.`（不区分大小写），且前缀之后必须有非空内容；`www.` 形式在打开时补全为 `https://` |
| 文件路径 | 需 `capsule_path_enabled` 为 `1`；接受盘符形式（如 `C:\`、`D:/`）与 UNC 形式（`\\server\share`），但路径段不能为空 |
| 路径排除 | 含 `shell:`、`::{GUID}` 或空字节的串不当作路径 |
| 类型确认 | 路径必须实际存在：目录显示为文件夹，文件显示为文件，取不到元数据则不提示 |
| 优先级 | 先判网址再判路径；网址文本不会再被当作路径 |
| 去重 | 同一类型同一文本在 1200ms 内只提示一次 |

只有文本记录参与判定：图片与文件（`CF_HDROP`）记录不触发胶囊。保险箱内的私密复制走独立通道（`paste::sensitive_clipboard_sequence`），永远不触发胶囊。

## 3. 界面行为

胶囊是独立的 Tauri 窗口（标签 `capsule`，入口 `capsule.html`），默认 460×76 逻辑像素，无边框、透明背景、置顶、不占任务栏、不可缩放、不抢焦点（Windows 上使用 `WS_EX_NOACTIVATE`，并复用主窗口的 `WS_EX_TOOLWINDOW`）。窗口在启动时创建一次并保持隐藏，显示与隐藏复用同一个实例；连续复制不同内容只更新同一个窗口的内容，不会堆叠新窗口。

- 显示：定位到鼠标所在显示器顶部居中，按该显示器 DPI 缩放换算物理像素，播放淡入。
- 倒计时：停留时长由设置项决定（3–10 秒，默认 5 秒）；鼠标移入暂停、移出从剩余时间继续。
- 关闭：点击关闭按钮、按 `Esc`、点击胶囊外部（低层鼠标钩子判定落在窗口矩形外），或倒计时结束淡出。
- 「打开」按类型分发：网址交给系统默认浏览器（`ShellExecuteW`），文件用 `SHOpenFolderAndSelectItems` 在资源管理器中定位并选中，文件夹用 `ShellExecuteW` 直接打开；无论成功或失败都会隐藏胶囊，避免留下吞掉点击的透明窗口。
- 图标：默认使用内置的链接/文件/文件夹矢量图标，用户可在设置中替换为自定义图片；自定义图标以 `data:` URI 传给窗口，读取失败时回退默认图标。

## 4. 设置项

设置页「剪贴板历史」分区末尾新增「链接胶囊」两组卡片，改动即时写入设置表，无需重启主窗口。

| 设置键 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `capsule_enabled` | 布尔 | `1` | 总开关；关闭时其余行变灰且不可操作 |
| `capsule_url_enabled` | 布尔 | `1` | 是否识别网址 |
| `capsule_path_enabled` | 布尔 | `1` | 是否识别文件路径 |
| `capsule_duration_seconds` | 整数 | `5` | 停留时长，限定 3–10 秒，越界时提示「停留时长需在 3 到 10 秒之间」 |
| `capsule_icon_url` | 字符串 | 空 | 网址胶囊的自定义图标路径 |
| `capsule_icon_file` | 字符串 | 空 | 文件胶囊的自定义图标路径 |
| `capsule_icon_folder` | 字符串 | 空 | 文件夹胶囊的自定义图标路径 |

图标行显示当前状态：已自定义时显示「已自定义 · 文件名」，否则显示「默认」；每行提供「选择图片」与「恢复默认」。选择与恢复都会先核对存储身份（存储目录切换期间拒绝执行），成功后重新读取设置。

## 5. 与剪贴板历史的关系

胶囊只是提示层，两者互不影响：

- 触发胶囊的文本仍然是普通剪贴板记录，照常入库、去重、参与 TTL 清理与容量淘汰。
- 胶囊不读取记录正文，因此不产生额外的解密或全文查询。
- 关闭总开关后，采集、历史列表与粘贴行为完全不变，只是不再弹出胶囊。
- 7 个 `capsule_*` 键已加入 `src-tauri/src/db.rs` 的 `EXPORT_SETTING_KEYS`，因此随备份导出与导入；三个布尔键参与取值校验，时长键限定 3–10。胶囊展示内容本身始终不进备份。

## 7. 平台支持与已知限制

- 目标平台为 Windows x64，与当前发布线一致；macOS/Linux 未实现、未验证。
- 多显示器：按鼠标所在显示器定位并做 DPI 换算，单显示器（1600×1000，缩放 2 倍）已实测；混合 DPI 多屏与任务栏自动隐藏未做桌面验证。
- 全屏应用与游戏上方：置顶窗口可能被系统或全屏优化遮挡，未验证。
- 超长路径在胶囊内按单行截断显示（120 字符后省略），完整内容需通过「打开」查看。
- 自定义图标仅支持本地图片文件（png/jpg/jpeg/gif/webp/svg/bmp，上限 512 KiB），不做压缩。
- 磨砂效果：胶囊窗口使用 `backdrop-filter: blur(40px) saturate(180%)`，但 WebView2 在透明置顶窗口上取不到背后内容做模糊，实测计算值为 `none`，视觉上呈现为半透明填充而非真实背景模糊；如需真实模糊需改用平台级 backdrop 效果（评估 `window-vibrancy` 的 Win11 Acrylic/Mica，Win10 需回退），当前版本未实现，仅记录在 TODO 的 C-06。
- 运行时依赖：WebView2 **Evergreen 运行时**（浏览器本体）不随包，启动时加载系统安装的版本，目标机需已装 WebView2 Runtime（Win11 自带，Win10 多数已有）；但 `WebView2Loader.dll`（约 160 KB 的加载器）是 exe 的静态导入依赖，**必须与 exe 同目录**，缺失时进程无法启动（`STATUS_DLL_NOT_FOUND`）。便携分发时两者缺一不可，MSI 安装包则不受影响。
- 打包：本机未安装 NSIS 3.x，`bundle.targets = all` 中的 NSIS 目标在构建时被跳过，本地构建只产出 MSI 与便携 EXE；该配置保持不变，安装了 NSIS 的环境仍可产出 NSIS 安装包。
- 更新签名：本轮产出的 MSI 与便携 EXE 均未附 `.sig`，因为自动更新私钥缺失（`src-tauri/updater.pub` 无配对私钥）。这是既有问题，不属胶囊功能引入，见 TODO 的 U 项。
