# 链接胶囊：复制链接与路径时的快捷操作

2026-10-25。用户要求「复制链接或文件路径时在屏幕顶部弹出一个可点击的胶囊」。2026-10-26 二期迭代新增：弹出位置自定义、修饰键门控、悬停展开全文、应用黑名单与全屏不弹（见第 4、5 节）。本页说明功能范围、识别规则、界面行为与设置项，供源码实现、评审和验收使用；实现进度与验收状态统一维护在 [TODO](../TODO.md)。

胶囊是剪贴板采集的旁路提示：它不改变普通记录、不新增业务表，也不进入备份。源码、设置项、中英文文案、窗口入口与原生命令均已接入，并在隔离桌面副本上完成真实剪贴板触发与窗口交互验证（见第 6 节）。

## 1. 功能概述

主窗口在后台监听剪贴板时，若新复制的文本是一个网址或一个存在的本地文件/文件夹路径，就在屏幕顶部显示一个独立无边框窗口（胶囊）。胶囊左侧显示类型图标，中间显示截断后的内容，右侧提供「打开」与「关闭」操作。停留时间到后自动淡出，鼠标悬停时暂停倒计时。

- 胶囊只对**本次复制动作**提示，不回溯历史记录。
- 提示内容不写入数据库，不复用剪贴板记录的 ID 或时间戳。
- 关闭胶囊不影响主窗口，也不影响剪贴板历史本身。

## 2. 识别规则

原生侧在写入普通记录后做一次判定，命中才显示胶囊。判定顺序与边界：

| 条件 | 规则 |
| --- | --- |
| 开关 | `capsule_enabled` 不为 `1` 时一律不提示 |
| 文本清洗 | 先 `trim`，再按需去掉首尾成对的双引号；空串、超过 2048 字符、含控制字符时不提示 |
| 网址 | 需 `capsule_url_enabled` 为 `1`；前缀为 `http://`、`https://` 或 `www.`（不区分大小写），且前缀之后必须有非空内容；`www.` 形式在打开时补全为 `https://` |
| 文件路径 | 需 `capsule_path_enabled` 为 `1`；接受盘符形式（如 `C:\`、`D:/`）与 UNC 形式（`\\server\share`），但路径段不能为空 |
| 路径排除 | 含 `shell:`、`::{GUID}` 或空字节的串不当作路径 |
| 类型确认 | 路径必须实际存在：目录显示为文件夹，文件显示为文件，取不到元数据则不提示 |
| 优先级 | 先判网址再判路径；网址文本不会再被当作路径 |
| 去重 | 同一类型同一文本在 1200ms 内只提示一次 |

只有文本记录参与判定：图片与文件（`CF_HDROP`）记录不触发胶囊。保险箱内的私密复制走独立通道（`paste::sensitive_clipboard_sequence`），永远不触发胶囊。

二期在识别之前增加了四层门控，按序短路（任一命中即不提示，且不影响剪贴板历史采集）：

| 门控 | 规则 |
| --- | --- |
| 应用黑名单 | `capsule_blacklist`（逗号分隔进程名，`*` 前缀可选）命中前台进程时不提示；进程名比较忽略大小写与 `.exe` 后缀，取不到前台进程名时放行。名单缓存在内存（30 秒或设置变更后失效） |
| 全屏应用 | `capsule_fullscreen_enabled` 为 `1` 时，前台窗口完整覆盖所在显示器且无标题栏/边框（独占或无边框全屏）则不提示；普通「最大化」窗口不在此列；桌面（`Progman`/`WorkerW`）不算全屏；检测失败时放行 |
| 修饰键 | `capsule_trigger_mode` 为 `modifier` 时，仅当 `capsule_modifier_key`（`ctrl`/`alt`/`shift`）在复制时按住才提示；`always` 为默认，每次复制都提示 |
| 去重 | 同一类型同一文本 1200ms 内只提示一次（一期既有） |

## 3. 界面行为

胶囊是独立的 Tauri 窗口（标签 `capsule`，入口 `capsule.html`），收起态 460×76 逻辑像素，无边框、透明背景、置顶、不占任务栏、不可缩放、不抢焦点（Windows 上使用 `WS_EX_NOACTIVATE`，并复用主窗口的 `WS_EX_TOOLWINDOW`）。窗口在启动时创建一次并保持隐藏，显示与隐藏复用同一个实例；连续复制不同内容只更新同一个窗口的内容，不会堆叠新窗口。展开全文时窗口临时增高到 460×212 并保持原定位锚点（顶部/底部/鼠标/固定模式各自不变），收起或隐藏时恢复 76 高，避免留下不可见的点击遮挡区域。

- 显示：定位由 `capsule_position_mode` 决定（见第 4 节），按该显示器 DPI 缩放换算物理像素，播放淡入。多显示器时取鼠标所在显示器。
- 倒计时：停留时长由设置项决定（3–10 秒，默认 5 秒）；鼠标移入暂停、移出从剩余时间继续。
- 展开全文：点击文本区切换展开气泡（限高约 124 逻辑像素内部滚动，可选中、可右键复制），再次点击或移出胶囊即收起并恢复倒计时。窗口高度由原生命令 `capsule_set_expanded` 同步调整；WebView 自身无法越过 76px 窗口，仅靠 CSS `height: auto` 会裁掉操作行与正文。
- 拖动记忆：位置模式为「固定位置」时，按住胶囊空白区拖动超过 6 逻辑像素进入原生拖动（拖动不触发点击，倒计时暂停），松手后保存坐标（物理像素）并立即生效；设置页提供「重置位置」回到顶部居中。
- 关闭：点击关闭按钮、按 `Esc`、点击胶囊外部（低层鼠标钩子判定落在窗口矩形外），或倒计时结束淡出。`Esc` 由新增的 Windows 低层键盘钩子（`WH_KEYBOARD_LL`，只观察不吞键）处理：胶囊不可聚焦，键盘事件始终发给原前台应用，WebView 内的 keydown 监听在正常使用路径收不到该键；DOM 监听保留作为兜底。
- 「打开」按类型分发：网址交给系统默认浏览器（`ShellExecuteW`），文件用 `SHOpenFolderAndSelectItems` 在资源管理器中定位并选中，文件夹用 `ShellExecuteW` 直接打开；无论成功或失败都会隐藏胶囊，避免留下吞掉点击的透明窗口。
- 图标：默认使用内置的链接/文件/文件夹矢量图标，用户可在设置中替换为自定义图片；自定义图标以 `data:` URI 传给窗口，读取失败时回退默认图标。

## 4. 设置项

设置页「剪贴板历史」分区末尾新增「链接胶囊」两组卡片，改动即时写入设置表，无需重启主窗口。

| 设置键 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `capsule_enabled` | 布尔 | `1` | 总开关；关闭时其余行变灰且不可操作 |
| `capsule_url_enabled` | 布尔 | `1` | 是否识别网址 |
| `capsule_path_enabled` | 布尔 | `1` | 是否识别文件路径 |
| `capsule_duration_seconds` | 整数 | `5` | 停留时长，限定 3–10 秒，越界时提示「停留时长需在 3 到 10 秒之间」 |
| `capsule_icon_url` | 字符串 | 空 | 网址胶囊的自定义图标路径 |
| `capsule_icon_file` | 字符串 | 空 | 文件胶囊的自定义图标路径 |
| `capsule_icon_folder` | 字符串 | 空 | 文件夹胶囊的自定义图标路径 |
| `capsule_position_mode` | 枚举 | `top` | 弹出位置：`top` 顶部居中（默认）/ `bottom` 底部居中 / `cursor` 跟随鼠标（弹出时定格，越界翻转并钳制在屏内）/ `fixed` 固定位置（`capsule_fixed_x`/`capsule_fixed_y`，可在胶囊上直接拖动） |
| `capsule_fixed_x` / `capsule_fixed_y` | 整数 | 空 | 固定位置坐标（物理像素），为空时回退顶部居中 |
| `capsule_trigger_mode` | 枚举 | `always` | `always` 每次复制弹出；`modifier` 按住修饰键复制时才弹出 |
| `capsule_modifier_key` | 枚举 | `ctrl` | 修饰键门控使用的键：`ctrl` / `alt` / `shift` |
| `capsule_blacklist` | 字符串 | 空 | 逗号分隔的前台进程名黑名单（如 `game.exe,quake`），命中不弹；只影响胶囊，不影响剪贴板历史 |
| `capsule_fullscreen_enabled` | 布尔 | `1` | 全屏应用内不弹出（默认开启） |

图标行显示当前状态：已自定义时显示「已自定义 · 文件名」，否则显示「默认」；每行提供「选择图片」与「恢复默认」。选择与恢复都会先核对存储身份（存储目录切换期间拒绝执行），成功后重新读取设置。

黑名单支持「从当前前台应用添加」（读取最近一次复制时的前台进程名）与逐条删除；位置模式为「固定位置」时设置页出现「重置位置」按钮（改回顶部居中并清除坐标）。以上改动均即时写入设置表。

## 5. 与剪贴板历史的关系

胶囊只是提示层，两者互不影响：

- 触发胶囊的文本仍然是普通剪贴板记录，照常入库、去重、参与 TTL 清理与容量淘汰。
- 胶囊不读取记录正文，因此不产生额外的解密或全文查询。
- 关闭总开关后，采集、历史列表与粘贴行为完全不变，只是不再弹出胶囊。
- 7 个 `capsule_*` 键（一期）与 7 个二期键已加入 `src-tauri/src/db.rs` 的 `EXPORT_SETTING_KEYS`，因此随备份导出与导入；布尔键与枚举键参与取值校验，时长键限定 3–10，坐标键限定为空或整数。胶囊展示内容本身始终不进备份。

## 7. 平台支持与已知限制

- 目标平台为 Windows x64，与当前发布线一致；macOS/Linux 未实现、未验证。
- 多显示器：按鼠标所在显示器定位并做 DPI 换算，单显示器（1600×1000，缩放 2 倍）已实测；混合 DPI 多屏与任务栏自动隐藏未做桌面验证。
- 全屏应用与游戏上方：置顶窗口可能被系统或全屏优化遮挡。全屏门控已实现（第 2 节），但真实全屏应用未做桌面实测（QA 无法合法夺取前台），仅验证了分类路径与开关行为。
- 修饰键门控依赖「复制发生时按键仍按住」：剪贴板监听为事件驱动，若系统繁忙导致处理延迟超过按键时长，极短按键可能不触发弹出；正常人工复制（按住时间 >100ms）不受影响。
- 超长路径在胶囊内按单行截断显示（120 字符后省略），可点击文本区展开查看全文（二期）。
- 自定义图标仅支持本地图片文件（png/jpg/jpeg/gif/webp/svg/bmp，上限 512 KiB），不做压缩。
- 磨砂效果：胶囊窗口使用 `backdrop-filter: blur(40px) saturate(180%)`，但 WebView2 在透明置顶窗口上取不到背后内容做模糊，实测计算值为 `none`。因此底色采用灰玻璃渐变近实底（亮色 `rgba(252,252,253,0.94)→rgba(238,238,241,0.92)`、暗色 `rgba(58,58,60,0.94)→rgba(38,38,40,0.92)`，悬停时提亮）配合顶部 1px 高光与内描边模拟液态玻璃，保证任意壁纸下的可读性；`backdrop-filter` 声明保留，在支持的引擎上仍会叠加模糊。如需真实背景模糊需改用平台级 backdrop 效果（评估 `window-vibrancy` 的 Win11 Acrylic/Mica，Win10 需回退），当前版本未实现，仅记录在 TODO 的 C-06。
- 布局回归说明：胶囊内容行 `.capsule-row` 的 flex 规则必须无条件生效；早期版本该规则只写在展开态选择器下，导致普通态退化为 inline 流（文本不省略、关闭按钮折行）。已于二期后修复并经亮/暗主题、长路径省略、展开态、连续 10 次快速复制（单实例不堆叠）与一期识别矩阵 11/11 回归验证。
- 路径探测：路径语法检查（盘符/UNC 前缀、`shell:`/CLSID 排除）在剪贴板线程内完成，`std::fs::metadata` 改到 `spawn_blocking` 后台线程执行；不可达 UNC 或休眠盘符不再阻塞采集、生命周期 producer 与退出保存屏障。后台结果按复制代次校验，较新的复制会使旧探测结果作废，不会显示过期内容。
- 运行时依赖：WebView2 **Evergreen 运行时**（浏览器本体）不随包，启动时加载系统安装的版本，目标机需已装 WebView2 Runtime（Win11 自带，Win10 多数已有）；但 `WebView2Loader.dll`（约 160 KB 的加载器）是 exe 的静态导入依赖，**必须与 exe 同目录**，缺失时进程无法启动（`STATUS_DLL_NOT_FOUND`）。便携分发时两者缺一不可，MSI 安装包则不受影响。
- 打包：本机未安装 NSIS 3.x，`bundle.targets = all` 中的 NSIS 目标在构建时被跳过，本地构建只产出 MSI 与便携 EXE；该配置保持不变，安装了 NSIS 的环境仍可产出 NSIS 安装包。
- 更新签名：本轮产出的 MSI 与便携 EXE 均未附 `.sig`，因为自动更新私钥缺失（`src-tauri/updater.pub` 无配对私钥）。这是既有问题，不属胶囊功能引入，见 TODO 的 U 项。
