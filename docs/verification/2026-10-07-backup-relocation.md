## 实现

- [note_backup.rs](../../copy-creator/src-tauri/src/note_backup.rs)：活动/归档便签、顺序引用和来源快照；排除最近删除/外部文件内容。语义摘要覆盖标题、原正文、按序引用的类型/目标/显示名、来源及归档布尔状态，排除 note/ref ID、时间缓存与协议版本。相同语义跳过，冲突保留本机并恢复副本；导入重新生成引用/创建请求身份和本地 revision。schema 3 的独立来源 ID/内容摘要记录防重复导入，保留后续本机修改；随便签物理删除级联清除，允许以后显式重新恢复。
- [backup.rs](../../copy-creator/src-tauri/src/backup.rs)：默认 v3 与独立 AAD，读取加密 v2 和旧 JSON v0/v1；v2/旧 JSON 不能注入便签扩展。预览包含便签/引用/冲突/跳过数量。导出为一致 SQLite 读事务；便签/引用/来源与设置、Key、标签、密码箱同一导入事务。结果数量取实际事务处理结果。
- [storage.rs](../../copy-creator/src-tauri/src/storage.rs)：一致源读事务、目标写保留内校验及联合提交，携带未过期删除项、协议身份及恢复来源。目标设置存版本化暂存凭据（源/目标、目标摘要、原目标设置）；源路由失败保留旧连接/epoch。目标内容未变才允许重试刷新本次暂存，目标被改或不同来源拒绝；其他目标表、原库和外部文件保留。原先清空快捷键设置的路径已移除。
- 目录范围保持设置/密码箱/便签，未扩展为全库/图片搬迁。中英设置提示明确剪贴板/短语/翻译历史和应用图片留原目录，外部文件不移动。
- [backup_limits.rs](../../copy-creator/src-tauri/src/backup_limits.rs)：DB 长度/数量预检、逐项 JSON 预算、图片文件长度合计，最终按实际转义字节执行 74 MiB 载荷/100 MiB 文件硬上限。预算含少量保守结构开销，不能替代最终精确检查。大集合明显超限时不加载全部正文；Vec 扩容受 writer 上限约束。
- 加解密复用已有缓冲；预览/导入用 `Arc` 共享后端文件暂存，减少整文件复制。最多 2 个备份后台任务；slot 由实际 worker 持有。
- 图片 base64 解码、校验、写入准备文件移到 DB 锁外；提交前复核 epoch 和准备时的存在性，变化拒绝且清理文件。便签过期清理复用启动/小时维护路径，每次最多 100 条，避让待保存任务，不阻塞等锁；引用/来源级联清理。列表/恢复按七天逻辑期限过滤，不承诺物理删除恰在到期时发生。
