# 便签页面与查询接入记录

更新：2026-10-07。当前为实现及自动检查记录，桌面联合验收尚未完成。

## 本批实现

- 侧栏便签入口，单栏摘要列表/编辑，活动/归档/回收站，字面搜索、游标翻页。
- 页面首次使用才加载；列表隐藏不刷新，同一查询共用请求，只有一个在途和一个可替换待执行查询；旧代次/旧目录响应不覆盖当前列表。
- 编辑订阅当前便签，IME 组词期间不保存；切页后保存协调器继续存在。失败、冲突与标题草稿可在本机恢复稿入口重新打开；冲突可另存新便签或确认后载入已保存版本。
- 文件原生选择、复制地址、定位；链接引用、复制正文；归档、删除、恢复经过保存屏障。删除/放弃本机稿/重新载入有明确确认。
- 剪贴板卡片“收为便签”读取原记录完整快照，成功后打开独立便签；受保护 Key 与图片不展示入口。捕获与状态变更在页面生命周期之外保留未确认请求身份供重试。
- 原有设计 token、字体和主题复用。新增中文、英文文案。
- 标题草稿不写 DB，但也不按干净 LRU 淘汰，占用四份恢复稿额度，避免标题稿无限增长。
- 内部目录迁移凭据不再作为产品设置返回或接受 WebView 写入。

## 自动检查

在 `copy-creator/` 执行：

```powershell
node node_modules/typescript/bin/tsc -b
node node_modules/eslint/bin/eslint.js src/pages/NotesPage/index.tsx src/lib/noteActions.ts src/lib/notes.ts src/stores/notesWorkspace.ts src/App.tsx src/pages/ClipboardPage/ClipboardCard.tsx src/lib/noteCoordinator.ts
node --experimental-strip-types --test tests/*.test.ts
node node_modules/vite/bin/vite.js build --outDir ../output/optimization/R2-notes-ui-wip-20261007/frontend
```

结果：类型与定向 lint 通过；前端 30/30 测试通过。生产构建通过，便签页面 CSS 2.09 kB、页面 JS 9.62 kB，便签核心/工作区/操作另有共享异步 chunks。当前入口 JS 412.33 kB，生命周期共享 chunk 112.58 kB；不能只用入口大小宣称总包下降。

产物是中间构建，后续源码变化须重新验证；R0/R1 不变。当前 Rust 完整测试最近一次为第三批 108/108，新增文件命令只做过编译，后续需重跑全套。
