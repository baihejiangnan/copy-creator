# 保险箱交互原型验证

2026-10-12。用户在保险箱升级方案交付后要求继续，本轮完成 V-01 合成数据交互原型。主方案仍维护在[保险箱设计](../features/website-vault.md)，任务状态只维护在 [TODO](../TODO.md)。

## 产物与范围

原型位于 [docs/prototypes/vault/](../prototypes/vault/index.html)，包括 HTML、CSS、交互 JavaScript 和从应用复用的图标。使用 `redesign-existing-projects` 技能核对现有 `VaultPage`、样式和字体，沿用应用的 PingFang、蓝色强调、亮暗主题与圆角。预览启动方法见[原型说明](../prototypes/vault/README.md)。

新建首屏提供自定义、网站账号、服务器，更多预设支持展开、搜索和内部滚动。服务器默认只有 IP / 主机地址与认证密码；标题展开条目、字段值执行原型粘贴，复制/显示/编辑/删除各自独立。编辑支持自由字段、类型、敏感标记、排序、标签、非敏感摘要、原文保存、放弃和删除确认。锁定、自动锁定设置和密码生成器提供可操作界面，所有资料仅为本页内存中的合成示例。

原型不调用 Tauri、系统剪贴板、真实资料库、外部服务或系统按键。密码生成结果也是测试值；本轮没有使用真实 API Key、密码、恢复码或用户内容。页面锁定只是交互演示，不能视为真实密钥/内存清除。自动锁定策略选择不启动空闲计时，网址打开只给出演示提示。

## 尚未覆盖的边界

本轮完成的是界面原型。统一字段的原生载荷、旧数据适配、版本门闸、加密备份/主密码轮换/目录搬迁、原生保存以及 Windows 实际粘贴均未实施或验收；20 次原型操作不能替代设计要求的 20 次真实桌面输入验收。主应用已有的普通/私密粘贴、自动锁定和跨平台缺口继续保留。

布局检查使用浏览器视口尺寸，不代表 Windows 100%～200% 系统缩放验证。减少动态效果/透明度的 CSS 降级已写入，但媒体偏好未在本轮浏览器中强制实测。密码生成器仅演示当前默认字符组选项，正式应用的完整字符组选项与主密码修改能力继续保留在工程接入范围。本轮未提交、推送、打包或发布。
