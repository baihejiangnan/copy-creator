## 升级与验收边界

推荐 MSI；0.3.0 可按现有元数据协议发现更高版本。0.2.28/0.2.29 的旧升级器可能只打开 Windows Installer 参数帮助页，须手动下载安装 MSI 一次；0.2.26/0.2.27 旧便携客户端同样推荐手动过渡 MSI。升级前创建加密备份，不支持降回 schema 5。

本轮未启动真实桌面应用、安装 MSI、访问用户数据库/密码箱或操作系统剪贴板。实际最小化恢复/隐藏重开、空闲到期、退出重开，以及两个更新入口、UAC、安装后启动与资料保持仍待隔离桌面验收；发布和自动测试通过不等于这些验收完成。普通/托盘偶发粘贴失败、内存目标与既有联合验收缺口继续保留。macOS/Linux 继续准备，用户本次明确暂不发布其发行版；不因仅发布 Windows 而缩减它们的既有功能要求。任务状态以 [TODO](../TODO.md) 为准。
