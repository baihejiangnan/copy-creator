## 独立接手审查

另一个 Agent 只读审查 AGENTS、TODO、发布规则、更新说明、脚本及本轮验证记录，没有执行构建、推送或发布。结论：文档已足以指导 Windows 固定来源签名构建、源码推送、按 ID 核对草稿与匿名六文件验签；「能读懂流程」不代表当前所有工作区修改均可发行，也不代替真实执行证据。

本轮修正四点：补充真正「仅推源码」模板与完整交接提示词；明确共享工作区按内容拆分及 output 并非整体忽略；更新说明中「当前 0.3.0」改为历史证据；发布脚本自动断言构建前后 HEAD 一致。Agent 入口的当前验证导航以 TODO 为准。规则主位置仍为[发布规则](../features/release-rules.md)，用户提示词见[交接模板](../prompts/release-handoff.md)。
