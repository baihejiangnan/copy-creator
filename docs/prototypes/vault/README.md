# 保险箱交互原型

入口：[index.html](index.html)。产品方案见[保险箱设计](../../features/website-vault.md)，实际检查分为[初版验证](../../verification/2026-10-12-vault-prototype.md)与[身份原型续轮](../../verification/2026-10-13-vault-identity-prototype.md)。

从仓库根目录启动静态预览：

```powershell
python -m http.server 8766 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:8766/docs/prototypes/vault/`。没有前端构建步骤，不启动 Tauri。

首页是「身份档案」，可打开个人/工作身份，查看邮箱、手机号与关联服务；「全部资料」可以直接查找服务条目并按身份筛选，「独立资料」无需关联身份。新建身份支持个人/工作/自定义起点；新建服务继续提供自定义、网站账号、服务器及更多预设。编辑时可关联多个身份，并为网站账号记录登录方式与说明；关联不复制身份字段或共用密码。删除身份保留其服务资料。

先点示例目标输入框，再点身份或服务中的字段值。编辑继续支持增删、改名、排序、敏感标记、标签与摘要选择。顶部可切换主题、语言和重置示例。

页面全部使用合成资料，仅在当前页内存保存。复制按钮使用 30 秒的原型暂存区，粘贴只操作本页示例输入框；不访问系统剪贴板、真实保险箱、数据库或原生命令。锁定仅展示界面状态，自动锁定选项仅作界面演示；没有真实认证、加密、备份、目录迁移或系统焦点交接。

字体引用仓库现有 `copy-creator/public/字体/`，图标由 `copy-creator/src/components/Icons.tsx` 复用；没有新增第三方依赖或外部资源请求。初版截图与逐次检查结果在 `output/vault-prototype/`；身份续轮的纯模型检查脚本与结果在 `output/vault-identity-prototype/`，不属于应用发行物。身份续轮因浏览器自动安全检查拒绝访问而未完成浏览器交互和视觉验收，初版截图不能代表当前页面。
