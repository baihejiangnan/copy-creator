# 短语界面改版预览

[打开交互 HTML](phrase-notebook.html)。可直接用浏览器打开；预览复用仓库里的苹方字体，移走单个 HTML 后会回退到系统字体，无需安装依赖。

本轮按用户要求仅制作独立预览，应用工程、原生能力和数据库均未改动。界面暂名「随手记」：同一条记录用于日常记录、编辑和需要时粘贴，不划分便签/短语类型。

- 顶部只保留一行搜索、分组选择和新建；点击新建后展开记录区，收起后继续保留草稿。标题可选。
- 点击卡片查看与编辑；正文、标题和所属分组自动保存。点击星标加入常用。
- 分组下拉菜单统一收纳全部、未分组、常用及自建分组，显示数量并支持搜索；新建与整理分组放在菜单底部。分组支持改名、换色和上下移排序；删除分组后所有记录移至未分组。
- 记录可归档、移到回收站、恢复；回收站内可永久删除。
- 「粘贴」仅向页面的试用文本框插入完整正文，保留换行，并替换当前选区；不访问系统剪贴板或外部窗口。
- 页面上方可切换亮暗主题，以及 520×680、440×420、780×680 三种模拟窗口。视口更窄时按可用宽度适配。
- 所有示例均为合成内容。浏览器存储使用独立键 `copy-creator-phrase-notebook-preview-v1`；底部可重置。

卡片沿用现有短语页的 `cardEnter`、55ms 阶梯入场、悬停正文/标题位移、色条与阴影反馈，分组和按钮保持现有缓动与按下缩放。增加减少动态效果偏好适配。

已检查 JavaScript 语法、浏览器新建、编辑/换组、刷新保留、分组改名/换色/排序/搜索、删除分组保留记录、完整正文模拟粘贴、常用、归档、删除/恢复及亮暗/最小窗口布局。此结果只适用于 HTML 原型，不代表桌面原生保存、粘贴或应用功能验收。
